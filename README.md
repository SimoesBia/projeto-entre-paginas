# Entre Páginas

Aplicativo acadêmico de clube de leitura e biblioteca digital, desenvolvido com Ionic e Angular Standalone. O app permitirá explorar livros da Open Library, organizar uma estante pessoal e acompanhar os desafios do clube.

## Ordem de desenvolvimento

| Ordem | Responsável | Entrega |
| --- | --- | --- |
| 1 | Kaline | Estrutura Ionic + Angular Standalone, Home, página da equipe, navegação e diretiva do livro do mês |
| 2 | Bruna | HttpClient, LivroService, três métodos GET (busca, assunto e detalhes de uma obra) e página Biblioteca |
| 3 | Hugo | Dois pipes personalizados e dois pipes nativos aplicados na interface |
| 4 | Rosana | Diretivas, bloco `@if`, BibliotecaService e Minha Estante com localStorage |
| 5 | Kauã | Bloco `@for`, detalhes com parâmetro de rota, página Clube de Leitura e progresso dos desafios |

## Como trabalhar em sequência

1. Kaline inicia o aplicativo e acrescenta ao README os comandos para instalar e rodar o projeto.
2. Cada integrante aguarda a etapa anterior entrar na `main`. Depois, atualiza sua `main` local e cria uma branch para sua etapa.
3. Ao terminar, testa sua parte, abre um Pull Request para a `main` e avisa a próxima pessoa após o merge.

Na apresentação, cada integrante explica o que fez, mostra onde está no código e demonstra onde aparece na tela. A entrega final será feita pelo GitHub e em ZIP pelo Teams.
